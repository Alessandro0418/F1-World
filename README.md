# F1 World 🇺🇸

**A Formula 1 web application built with React and the OpenF1 API.**

F1 World is a personal web development project that brings Formula 1 information together in a responsive and user-friendly interface. It allows users to explore session information, weather conditions, the race calendar, and the current top three drivers in the Drivers' Championship.

The project was developed for educational and portfolio purposes, with a focus on frontend development, API integration, and responsive user interface design.

**[[Live Demo](https://f1-world-gamma.vercel.app/Home)]**

## Features

- **Home Page/Driver Standings** — An overview of the application with its main sections and the current top three drivers in the Drivers' Championship.
- **Session Overview** — Explore Formula 1 session information and related data.
- **Weather Information** — View weather conditions associated with Formula 1 events.
- **Race Calendar** — Browse Formula 1 calendar information.
- **Responsive Design** — An interface designed to adapt to different screen sizes and devices.

## Tech Stack

- **JavaScript** — Application logic and dynamic data handling.
- **React** — Component-based user interface development.
- **Vite** — Development server and build tooling.
- **React Router** — Client-side navigation between application pages.
- **React-Bootstrap** — UI components and responsive layout.
- **CSS** — Custom styling and visual presentation.
- **OpenF1 API** — Formula 1 data integration.

## Getting Started

To run F1 World locally, follow the steps below.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd f1-world
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To generate an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

_Note: The commands above assume the standard Vite scripts are configured in `package.json`._

## API Integration

F1 World uses the [OpenF1 API](https://openf1.org/) to retrieve Formula 1 data and present it through the application's interface.

The API integration supports the data-driven features of the project, allowing relevant Formula 1 information to be displayed dynamically.

For further information about available endpoints and data, refer to the [OpenF1 documentation](https://openf1.org/).

## Project Purpose

F1 World was created as a personal project to strengthen practical frontend development skills and explore the integration of external APIs into a React application.

The project demonstrates experience with component-based architecture, client-side routing, responsive layouts, and dynamic data rendering.

# F1 World 🇮🇹

**Un'applicazione web dedicata alla Formula 1, sviluppata con React e OpenF1 API.**

F1 World è un progetto personale di sviluppo web che raccoglie informazioni sulla Formula 1 in un'interfaccia intuitiva e responsive. Consente di consultare informazioni sulle sessioni, condizioni meteorologiche, calendario delle gare e i primi tre piloti dell'attuale classifica mondiale piloti.

Il progetto è stato sviluppato a scopo educativo e per il portfolio personale, con particolare attenzione allo sviluppo frontend, all'integrazione di API esterne e alla realizzazione di interfacce responsive.

**[[Live Demo](https://f1-world-gamma.vercel.app/Home)]**

## Funzionalità

- **Home Page/Classifica Piloti** — Panoramica dell'applicazione con accesso alle sezioni principali e visualizzazione dei primi tre piloti dell'attuale classifica mondiale piloti.
- **Session Overview** — Consultazione delle informazioni relative alle sessioni di Formula 1.
- **Informazioni meteorologiche** — Visualizzazione delle condizioni meteorologiche associate agli eventi di Formula 1.
- **Calendario gare** — Consultazione delle informazioni sul calendario della Formula 1.
- **Design responsive** — Interfaccia progettata per adattarsi a diverse dimensioni dello schermo e dispositivi.

## Tecnologie utilizzate

- **JavaScript** — Logica applicativa e gestione dinamica dei dati.
- **React** — Sviluppo dell'interfaccia tramite componenti.
- **Vite** — Server di sviluppo e strumenti di build.
- **React Router** — Navigazione tra le pagine dell'applicazione.
- **React-Bootstrap** — Componenti UI e layout responsive.
- **CSS** — Personalizzazione dello stile e dell'aspetto grafico.
- **OpenF1 API** — Integrazione dei dati relativi alla Formula 1.
